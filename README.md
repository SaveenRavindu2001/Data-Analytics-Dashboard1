# Employee Performance Analysis Dashboard | Excel

## Project Objectives

An interactive Employee Performance Dashboard developed using Microsoft Excel to analyze and visualize employee performance across different departments, regions, and months.

## Dataset used
- <a href="https://github.com/SaveenRavindu2001/Data-Analytics-Dashboard1/blob/main/Employee%20Performance%20Data.xlsm">Dataset</a>

## Questions (KPIS)


- How many employees are there in total?
- Which department has the highest productivity?
- Who are the top 5 performing employees?
- What is the average employee achievement?
- Which region has the highest task completion rate?
- How does employee productivity change monthly?

## Process

1)Data Collection – Gather employee performance data.
2)Data Cleaning – Remove duplicates, blanks, and incorrect values.
3)Data Transformation – Organize and prepare data for analysis.
4)Data Analysis – Use Pivot Tables and calculations to analyze performance.
5)KPI Development – Calculate key performance indicators.
6)Data Visualization – Create charts and graphs to present insights.
7)Dashboard Development – Build an interactive dashboard using Excel Slicers.
8)Insights & Reporting – Identify performance trends and support data-driven decisions.
